# 安全与隐私 / Security And Privacy

本目录说明 Product Core 的个人信息告知、系统使用边界、知悉留痕和客户委托处理合同模板。它不保存客户原始个人信息、签署合同、凭据或目标环境运行记录。

## 阅读入口

1. [个人信息处理与系统使用治理](个人信息处理与系统使用治理.md)：产品实现、客户配置、处理角色、知悉证据、保存期限和发布检查。
2. [个人信息委托处理协议模板](个人信息委托处理协议模板.md)：客户作为个人信息处理者、产品实施或运维方作为受托人的可填写合同附件模板。

## 真源边界

- 运行时公开文案与内容指纹：`web/src/common/legal/**`。
- 客户主体、联系渠道、部署位置和处理方清单：`config/customers/<customer-key>/customer-config.example.js` 的 `legalNotice`。
- 知悉回执：后端追加式 `runtime_audit_events`，不是前端本地偏好，也不是概括授权同意。
- 账号、权限、业务事实、附件和审计的实际处理：当前 schema、usecase、API、部署配置和测试。
- 已签署委托处理协议、客户内部制度和真实联系方式：客户受控资料或合同系统，不进入 Product Core。

文档只说明当前产品合同，不替代客户法务判断。交付前应由个人信息处理者确认主体、联系渠道、处理方、跨境情况和保存口径与真实部署一致。

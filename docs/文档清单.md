# 文档清单 / Document Inventory

查具体文件时用本清单；不确定先读什么时，回到[文档首页](README.md)。本页登记长期维护文件及归档入口，不记录产品能力或运行状态。

## 使用规则

| 要查什么 | 查找方式 |
| --- | --- |
| 当前文档 | 按下方目录分类查路径与用途 |
| 历史文件 | [归档索引](archive/README.md)，逐文件登记在最近目录 README |
| 当前实现或交付状态 | [当前真源](当前真源与交接顺序.md)，再核对代码与目标证据 |
| 文档增删、改名或职责变化 | 按[索引同步规则](README.md#索引同步--index-sync)维护本清单及相关入口 |

`node --test scripts/qa/docs-inventory.test.mjs` 检查当前维护 Markdown、归档登记、路径与锚点；正文修改且职责不变时，通常无需更新本清单。

# 仓库与品质 / Warehouse Quality

仓库负责实物点数、收发存及查货包装；IQC 负责质量事实，业务决定生产质量异常方案并办理实际发货。桌面任务中心、手机岗位任务和业务页面使用同一领域动作。本文描述当前工作区合同，目标是否生效须核对迁移、客户配置和运行版本。

## 仓库

| 能力 | 业务入口与事实 |
| --- | --- |
| 采购到货点数 | 采购订单登记实际到货，生成采购收货草稿与 IQC 待办；实点数量归仓库，送货标示数量只作差异参考 |
| 材料正式入库 | 采购入库核对质量关口后确认 `POSTED`，形成库存 `IN` |
| 发料外发裁片 | 在生产订单关联裁片加工合同，正式发料后确认外发 |
| 工序回货点数 | 生产工序填写仓库实点数量，记录 `OUTSOURCE_RETURN` 后交 IQC；WIP 回货不增加成品库存 |
| 成品正式入库 | 在生产订单按已完成手工的批次登记收仓草稿，在生产记录确认 `POSTED`；库存增加但待检 / 待包装数量禁止发货 |
| 查货与包装 | 对明确的已过账成品收仓记录安排包装，检验与业务包材确认通过后查货、包装；不重复增加库存 |
| 库存查看 | `inventory_txns` 为流水真源，`inventory_balances` 为余额，`inventory_lots` 为批次；待检 / 待包装 / 可发货数量来自收仓与工序事实 |
| 入库后异常处置 | 按批准方案执行库存处置及受限冲正；仓库数据范围同时约束首次执行、重放和冲正 |

## 仓储入口与库存口径

仓库操作集中在“仓储管理”：库存查询、入库办理、出库办理和库存作业。入库按采购收货、成品入库、委外回货分类；出库按销售出货、生产领料、委外发料、库存预留分类。办理页复用原有来源单据及权限，销售和生产的业务入口仍保留。页签只展示当前账号获准的能力。

| 数量 | 计算与使用边界 |
| --- | --- |
| 账面数量 | 已过账流水汇总，包含受限批次及待检、待包装成品 |
| 已预留 | 当前有效的销售订单预留；释放预留不增加实物库存 |
| 未预留数量 | 账面数量减有效预留，下限为零；API 保留 `available_quantity`，不能据此断定允许领用或发货 |
| 可领用数量 | 材料的未预留数量，批次须为 ACTIVE；非材料或受限批次为零，具体领料仍核对业务来源、单位和权限 |
| 受限库存 | HOLD、REJECTED 或 DISABLED 批次的全部账面数量；未分批次库存按普通库存处理 |
| 待检 / 待包装 | 由成品收仓与工序事实确定，不能与其他数量列简单相加 |
| 可发货数量 | 成品未预留数量扣除待检、待包装限制并取非负值，受限批次为零；实际出货仍须满足来源单、放行和库存校验 |

库存流水返回实际来源单号及可访问的来源入口。采购退货、入库更正定位原收货单，委外处置定位原回货；库存盘点、调拨及调整定位库存作业，生产异常定位异常单。来源编号与反向流水的原流水关联保留，不用前端猜单号；点击仍受来源单据权限限制。历史无来源或已无法解析的记录保持可查询，不伪造可打开的单据。

## 盘点复核与完成记录

1. 从库存查询勾选明确的库存行形成盘点范围，单次最多 200 行，逐行保留存货、规格、仓库、批次、单位及账面数量。当前范围是已存在的库存余额；不是全仓冻结或未入账物料的期初导入。
2. 填写实盘数量和原因，后端从真实余额核对账面数量并计算差异。同一库存粒度不能在一单重复登记，各单位精度分别校验。
3. 提交后冻结明细，复用库存审批流程。复核人查看逐行账面数、实盘数和差异；创建人不能审批自己的盘点或调整。电脑与手机办理均先读取完整明细，读取失败时不能批准。
4. 批准后由仓库确认过账。后端重新核对账面数量，期间发生出入库则整单拒绝过账，保留原快照，取消原作业后重新盘点并复核；不自动把旧实盘数套用到新余额。
5. 全部零差异也可以完成，保留已过账作业与复核证据，但不新增库存流水；混合明细只为非零差异生成流水。重复请求不重复入账。
6. 驳回不改变库存；纠错重新登记。取消未过账单不改变库存，取消已过账单按现有依赖、权限、预留及受限数量规则追加反向流水，保留原单与原流水。活动审批先按流程取消，再处理来源单。

调拨仍按来源、目标仓库与可用库存校验后直接过账；人工调整与盘点都必须复核。历史已过账或已取消的盘点事实保留原有证据，不补造审批人或审批时间；升级后新盘点统一经过复核。

## 品质

已生效质检的结果纠正会保留原判定证据，并创建待判定的复检单。纠正后的复检不能取消，必须完成新的判定；待判定期间仍保持批次待检和出货阻断，不能通过取消复检跳过质量关口。

检验人由后端按当前登录账号记录，页面和导出显示该账号的姓名（未填写姓名时使用登录名）；不接受客户端代报检验人，历史缺失不推测补填。

采购来料、委外回货、出货前成品检验和生产分段质检均须记录实际检查项：项目、要求 / 依据、实际情况、符合或异常、全检或抽检；抽检须写范围或数量，不适用须说明原因。未检不能作为合格依据；不合格和让步必须同时记录异常项与处置理由。各类预填检查项目只作填写起点，默认均为未检。

列表明确选择检验类型，默认采购来料；从采购、委外回货或出货来源进入时，类型与来源条件保持一致。默认“当前记录”排除已被更正替代的原单，状态统计与 CSV 导出使用同一范围；“含已替代记录”用于追溯，并明确显示已替代标记、原结果、更正原因和前后单号。详情可互相打开原单与替代单；当前记录不等于已合格，仍可能待检或不合格。

IQC 按正式 `quality_inspections` 记录来料颜色、裁片颜色与尺寸、皮套以及成品各关口结果。不良比例使用 `defect_rate_operator / defect_rate_percent`，历史缺值不猜测回填；比例不自动换算报废、退货或库存数量。

检验不合格保留原检验事实，生产批次进入 `REJECTED` 并交业务决定方案。返工与重做建立保留异常来源的新 WIP 子批，再按目标工序重新点数和检验。成品检验、针检、抽检与条件客户验货继续保留；业务确认包装版面不代替 IQC。

生产让步只针对审批关联的那一次不合格检验。执行后保留原不合格事实，继续生成冻结路线中的下一关；只有最后一个必需关口结束才将批次放行。后续关口失败仍阻断生产。撤销让步仅能取消尚未提交的下一关草稿；已有后续提交、判定、在制子批或库存依赖时拒绝撤销，避免抹去已发生事实。

同一检验结果在响应丢失后可原样重试，即使批次已进入下一关也返回原记录，不重复生成质检单或推进批次。改变检验人、检查内容、显式检验时间、不良比例或已提交的理由会被判为冲突，不能覆盖原判定。

批次质量状态 `HOLD / ACTIVE / REJECTED / DISABLED` 通过命名动作、version CAS 与 `inventory_lot_status_events` 留痕，质量事件不代替库存流水。

## 主链关系

1. 采购安排到货，仓库点数，IQC 检验，通过材料入库门禁后正式入库。
2. 仓库按裁片合同发料外发；裁片回厂由仓库点数，再由 IQC 检查颜色及尺寸规格。
3. 生产经理安排车缝，可本厂或委外；外发回货由仓库点数，IQC 进行皮套检验。
4. 生产经理安排手工，可本厂或委外；手工完成形成成品，仓库可先正式入库并记录库存。
5. 未完成检验的库存处于待检，检验通过后仍需仓库查货包装。包装批次用 `finished_goods_receipt_id` 绑定确切收仓、仓库与批次，不能用甲仓包装结果放行乙仓库存。
6. 质量关口与查货包装完成、出货放行通过后，由业务办理真实 `SHIPPED`，写库存 `OUT`。仓库与财务放行不等于出库；应收和开票以真实出货为来源。

## 异常分支与数量边界

| 方案 | 执行与追溯 |
| --- | --- |
| 原加工厂返工 | 冻结原厂与目标工序，生成新返工批和新合同，保留原质量结果 |
| 换加工厂返工 | 冻结其他厂商，对原货返工，不能执行时再换厂 |
| 补料重做 | 回到裁片工序，按新材料合同正式补发布料，不重复使用原批发料作为新料证明 |
| 放弃本批 / 报废 | 审批后执行正式处置；已有收仓事实的库存由仓库处理，不能仅关闭任务 |
| 让步、超领 | 沿用原有独立审批与领域执行边界 |

WIP 当前按整批回货并按整批不良处置。实点数量必须与本批数量一致；少收或多收须先核对，不能自动视为全批到货。分批回货、部分不良拆分未在本次提供。采购到货仍保留既有分批 / 分卷实际收货能力，两者不可混淆。

任务详情按正式单据关系展示当前账号可见的订单主链和异常分支；异常源单、原批次、子批与复检可追溯。看见处理链不产生其他岗位的办理权限。原任务、原检验、原收仓和执行事件保留；冲正必须没有后续加工、质检、合同等依赖并满足库存限制。

## 任务与事实

来源待办由领域事务同步。手动跟进、旧协同事件中的 `done / inbound_done / shipping_released` 只表示协同结果，不能充当检验完成、收仓过账或真实发货的证据。任务办理页进入对应正式业务表单，保存成功后返回原任务并重新读取状态；业务页面保留相同办理入口。

历史已过账、来源为已完成包装的收仓事实保持原样，并占用原手工容量，不能重复收仓。升级前须检查旧未完成包装、旧包装来源草稿和冻结于旧岗位的活动异常 / 出货流程；不能用改写历史流程责任绕过升级预检。

## 预警规则

- 质量不合格与业务异常进入异常处理分类；异常处于 `ready` 或逾期时仍保持异常可见，终态进入已结束。
- 逾期、缺料、点数差异与出货风险分别显示，不以催办或任务完成解除业务门禁。
- 库存查询和负向库存动作统一保护待检 / 待包装数量，不能通过普通调整绕过禁止发货。

## 当前不做

PDA、条码枪、复杂库位策略、WMS 波次、自动补货、图片识别和复杂 AQL 算法不在本次范围。

# 交互设计 / UI Interaction Design

本目录维护 ERP 与效能工作台的界面结构、视觉与操作合同。[index.html](index.html) 是完整流程交互稿，组件设计直接调用共享 React 组件。工作台页面组合在实际页面上核对。修订由 Git 追踪，Figma 用于设计参考。参考方案的采纳与维护边界见[设计资产维护](设计依据.md#设计资产维护--design-maintenance)。

| 要核对什么 | 入口 |
| --- | --- |
| 页面布局、控件、状态和完整操作路径 | [最新可交互 HTML](index.html)，或工作台“交互设计” |
| 页面职责、状态、数据及验收行为 | [交互设计说明](交互设计说明.md) |
| 工具栏哪些统一、哪些由业务决定 | [业务工具栏的组合与差异](交互设计说明.md#business-toolbar-composition)；工作台“组件设计 → 业务工具栏组合”（`control=business-toolbar`）直接操作真实组件，保留四业务切换、职责标注和两类增长场景 |
| 页签放标题区还是查询区，分段和筛选怎么区分 | [页签分层与区域间距](交互设计说明.md#business-toolbar-composition)维护唯一规则；[页签与视图](/__dev/ui-design?page=controls&control=navigation)同屏操作下划线页签、圆角底轨和带数量的筛选按钮；“业务工具栏组合”对照采购查询与生产办理 |
| 为什么这样安排布局和动作 | [设计依据](设计依据.md) |
| 共享组件与组合用法 | 工作台“交互设计 → 设计样例” |
| 效能工作台页面组合与任务验收 | [工作台页面组合](交互设计说明.md#workbench-patterns)，可在[设计说明](/__dev/ui-design?view=specification&read=reference#workbench-patterns)打开各类型的实际页面 |
| 两端界面值的含义、条件变化与布局原因 | 工作台“交互设计 → 设计说明 → 工作中心” |

核对反馈时可在[操作反馈样例](/__dev/ui-design?page=controls&control=feedback)比较普通成功与可关闭的复制提示，在[反馈图解](/__dev/ui-design?view=rationale&topic=feedback)连续点选 Toast 查看叠放。弹窗的尺寸和留白见[弹窗图解](/__dev/ui-design?view=specification&topic=dialogs)和[结构与留白的取舍](/__dev/ui-design?view=rationale&topic=dialogs)。

演示使用共享组件与隔离本地状态，可切换成功、失败、结果未知，重试或重置。附件仅选择本地文件、不上传；CSV 与 HTML 打印稿在浏览器本地生成和下载，不写业务数据；讲解参数不写外观偏好。规则、设计表达、实际运行和业务验收分别核对。

“补充说明”（`/__dev/ui-design?page=controls&control=help`）直接操作共享 `SupplementalHelp`、业务字段说明、外观对比和完整页面帮助，核对悬停、键盘、点按固定、单个展开及弹窗内 Esc；输入草稿与警告保持可见，样例不写业务数据或账号偏好。

## 怎样阅读 / Reading

1. 打开 `/__dev/ui-design`，在“设计说明”或“设计依据”的顶部工具栏搜索图解，提交后从展开的目录中选主题。
2. 在图解下方的“查阅规则”展开当前小节，阅读区自动定位到规则开头。较长的规则可在同一正文区滚到末尾。正文直接取自正式文档；章节链接仍可直接定位。
3. 读完点“收起规则”，恢复原位置和入口焦点。主题、搜索和演示状态留在原处。

清除搜索恢复完整主题目录。用工具栏右侧的目录图标展开或收起目录；收起后仍可搜索。目录与正文独立滚动；窄屏选中主题后收起目录并回到正文。图解、已展开规则和搜索词可随链接打开或刷新。

可从[查找、下钻与返回](/__dev/ui-design?view=specification&topic=navigation)试一次查询与返回；从[整页、弹窗与抽屉](/__dev/ui-design?view=specification&topic=forms)切换并操作对应样例；从[状态与异常恢复](/__dev/ui-design?view=specification&topic=states)对照首次读取、同条件刷新与失败重试。编号、流程和对照的选用见[图解阅读](交互设计说明.md#图解阅读--illustrated-reading)。

## 预览入口 / Previews

顶部页签为“可交互设计、设计样例、设计说明、设计依据”。“可交互设计”用「桌面 ERP」「手机版」「登录页」切换预览，默认进入桌面 ERP。生产管理、任务管理、帮助中心和效能工作台从桌面稿的原菜单进入。“设计样例”直接打开组件设计。办理样例在桌面稿的“任务管理 → 办理样例”打开，返回保留任务列表的条件。

每个界面首次打开时加载。预览之间切换，或从设计说明、设计依据和设计样例返回，保留已经打开的页面、输入和演示状态。预览支持隔离浏览、全屏、重置和下载同一份 HTML。岗位帮助的全屏切换与布局重绘保留未提交的搜索词。预览须收到设计稿的渲染就绪确认；恢复可见时重新核对布局，隐藏期间暂停就绪计时。初始化失败、布局不可见或可见后 12 秒内未就绪时显示重载入口。点击“重新加载预览”或“重置演示”清空当前演示状态；预览只在浏览器本地执行，不写业务数据。

手机版独立占用预览区。工具栏宽度充足时，左侧同排选择身份、岗位和模拟状态，右侧提供设备支持范围、重置演示、下载 HTML 和全屏预览。窄屏只显示「预览设置 · 当前岗位或身份」「全屏」「更多」。点设置即可调整场景，「更多」收纳设备支持范围、重置和下载。独立下载的 HTML 在手机画面外提供身份与岗位选择。宽屏居中显示手机，窄屏直接铺满可用画布。任务列表在屏幕内滚动，底部导航、图片和附件弹窗受手机边框约束。“我的 → 帮助与手册”在手机内阅读和返回。切换工作入口、演示登录或退出时，顶部选项与当前界面同步。预览工具栏的“设备支持范围”打开[任务办理](/__dev/task-handling)，可查任务分类和适用设备。

桌面 ERP 和手机版的“状态模拟”使用共享 `AppSelect`，选中后保留用途与状态，清空后恢复正常内容并保留选择入口。两个界面各自保留模拟状态，重置演示只影响当前界面。桌面提供“切页等待”，手机提供首次加载、切换栏目、刷新、空白和失败状态，预览内重试或清除条件后同步当前状态。“页面状态样例”可打开组件设计中的“页面状态”，直接操作共享组件。HTML 保留单份、独立下载的场景表达，手机骨架仅使用现有卡片布局的静态占位；组件动画与真实几何在组件样例中核对。

业务界面的“边界压力”“压力 · 读取较慢”“压力 · 读取失败”共用正常列表与详情。实际记录、字段极值、明细、关联和附件的规模及操作见[压力状态说明](交互设计说明.md#boundary-preview)；表格工具中的“弹窗边界”直接打开可搜索、分页和返回的真实样例详情。

### 组件设计看什么

1. 点顶部“设计样例”进入组件目录，也可用 `/__dev/ui-design?page=controls` 直达。
2. “组件使用指南”固定在左侧顶部。组件按录入与选值、搜索与筛选、表格与分页、导航与视图、弹窗与抽屉、操作与反馈分组，组合样例单列。目录显示中文名，组件代码名在样例标题下方。各组可独立展开，也可在顶部点“展开全部”或“收起全部”。直达样例会展开所属组并滚动到选中项。
3. 搜索同时查找各组的用途、组件名和样例变体，并展开有匹配项的组。搜 `AppSelect` 可找到下拉选择，搜 `Toast` 可找到“操作反馈”。搜“分组下拉”并选中结果会打开对应变体，关键词保留在输入框。清除搜索可回到当前样例所属组。
4. 目录选择、样例变体与关键词随 URL、刷新及前进后退恢复。缩窄窗口时可继续查看聚焦的搜索提示。无结果时清除搜索会将焦点交回搜索框，可直接继续输入。浅深主题仅影响样例，重置演示只重置当前展示区域。

一级和分级内容目录的样式统一维护在 [directory.css](../../../web/src/common/components/navigation/directory.css)。调整后在仓库根运行 `node scripts/docs/project-manuals.mjs` 同步完整 HTML 交互稿的内嵌样式，再运行 `node scripts/docs/project-manuals.mjs --check` 核对。

#### 从用途找到组件

“组件使用指南”（`/__dev/ui-design?page=controls&control=components`）直接读取[正式组件入口](../../engineering/前端实现与交互约定.md#组件复用与使用入口--shared-component-entrypoints)，覆盖通用、业务组合和打印专用组件；打印组件的复用边界随表展示，完整打印专题由文档目录查阅。

有独立外观、状态或操作规则的通用入口提供组件样例。表单分区、明细行、选择栏和工具栏挂载点随完整任务展示。附件、流程进度和打印组件从选用表追溯到实际页面及专题，因为它们依赖单据和权限。Markdown、图表与工作台页面样板沿用设计说明、可视化规范和实际工作台页面。

| 要核对什么 | 样例 |
| --- | --- |
| 单行输入、多行备注、搜索及筛选 | “录入与选值”里的“单行输入”“多行文本”，以及“搜索与筛选”里的“搜索框”“筛选下拉”“筛选浮层” |
| 表格排序、选行与翻页 | “数据表格”操作 `AppTable`。“分页”操作表格内与独立两种呈现，核对 `AppPagination` |
| 目录定位与层级 | “导航与视图 → 目录导航”可切换分级目录和一级目录。指南可搜“目录导航”或 `Directory` 查看样例与用法 |
| 弹窗、抽屉与提示 | “业务编辑弹窗”“通用弹窗”“业务弹窗”“详情抽屉”“会话提示”各用正式组件。“抽屉内查看附件”核对逐层返回，“危险操作确认”核对动作前的后果、取消和确认，“操作反馈”核对动作后的消息和恢复 |
| 切换、空提示和提醒 | “导航与视图”展示内容页签、受控页签条和分段选择，“搜索与筛选”展示筛选按钮及按钮组，“操作与反馈”展示空提示和数字提醒。“页签与视图”和“页面状态”用于组合核对。进度视图和二级内容在“受控页签条”操作 |

“业务工具栏组合”（`/__dev/ui-design?page=controls&control=business-toolbar`）按需加载库存查询、采购订单、任务管理待办和历史记录，复用真实工具栏、表格、查询、筛选、详情与列设置。已访问业务保持挂载，往返保留本地搜索草稿、筛选、分页和选择；“恢复示例”回到初始状态。职责标注可关闭，分类增长与 30 项数据名单分开演示；假设分类不进入产品导航。查询、列设置与导出仅处理本地虚构数据，不读取业务记录、不保存账号偏好。

[多列明细](/__dev/ui-design?page=controls&control=business-form&example=wide-lines)直接使用 `AppSelect` 和 `BusinessLineItemsTable`，可切换长短名称、420px 窄区域和十列明细，默认核对两行名称和独立编码，再操作锁定值阅读、仓库搜索与清空；行为规则见[完整值读取](交互设计说明.md#select-overflow)。

“业务表单与明细”（`control=business-form`）操作正式整页表单、分区、普通明细、紧凑字段明细、联系人和长文本组件，对照三种入口的统一列头、外框及复制移除按钮，覆盖校验、增删及空态、离开保护和保存重试；“来源选择”（`control=source-picker`）操作正式来源选择弹窗，覆盖搜索、跨页选择、停用限制、取消与重开、加载、空列表和失败恢复。两类按需加载，只操作本地虚构记录。组件使用指南和各分类同源展示真实消费者名称与核对任务；设计页不附加业务快捷跳转，实际业务从正式入口独立核对并沿用业务权限。

#### 日期、搜索与分组选择

在[组件使用指南](/__dev/ui-design?page=controls&control=components)的“日期控件选用”表比较日期输入、日期时间和日期范围筛选。各行直达独立样例，核对即时选值、清空、快捷截止或倒置范围。

[筛选下拉](/__dev/ui-design?page=controls&control=filter-select)以任务管理的“办理人”为例。输入姓名缩小候选，选中后核对任务数，清空后恢复不限。规则见[下拉选择与清空](交互设计说明.md#select-controls)。

[下拉选择](/__dev/ui-design?page=controls&control=select)右侧提供基础选择、分组下拉和长名称。[分组下拉](/__dev/ui-design?page=controls&control=select&example=grouped)直接使用 `AppSelect` 和历史来源分组构造器，比较分类标题、缩进选项和勾选，操作单选、多选、清空与禁用状态；统一规则和当前使用入口见[分组选项](交互设计说明.md#grouped-select-options)。

[筛选与搜索](/__dev/ui-design?page=controls&control=filters)演示关键词、快捷条件和总筛选如何改变列表结果。电脑样例可连续调整记录范围和负责人，在右上角清空筛选，完成后手动收起。手机样例沿用筛选入口和浮层样式，快捷条件保持至少 44px 点击区，窄屏可横向滑动。位置与生效方式见[电脑版筛选气泡](交互设计说明.md#desktop-filter-popovers)。

[分组选择（单选／多选）](/__dev/ui-design?page=controls&control=chain-view-picker)复用流程探索的 `BusinessChainDesignPicker`。面板标明选择方式，尖角对准露在面板外的按钮。流程范围点选后收起，岗位高亮可连续勾选，示例步骤显示各自和共同参与的岗位，「全链路视角」清除全部高亮。

### 岗位帮助看什么

| 阅读任务 | 展示方式 |
| --- | --- |
| 交接与异常 | 业务链，在同一位置显示办理概览 |
| 连续办理 | 编号步骤；点击查看当前步骤、完成结果或恢复 |
| 简单查询 | 短路径；窄屏由同一场景数据生成纵向编号 |
| 局部操作位置 | 字母标注，联动对应示意 |
| 查字段、公式、条件与边界 | 直接进入“业务手册”，包含通用阅读、岗位交接、24 个业务页及工程用料专题 |

“操作图解”和三册手册共用一层导航与全文搜索，可直接进入。图解首页按岗位推荐，目录按业务模块分组；桌面目录与正文独立滚动，手机按需打开目录抽屉。三册按账号权限提供在线阅读，统一章节卡片、章内导航和前后章入口，并通过“下载手册”菜单下载当前可读整册的 HTML / Markdown；可按任务、字段、状态、别称或问题查找。

工程用料审批与采购生成有教学图解；正式帮助入口为 `/erp/help-center`，内容来自当前共享帮助定义与正式手册，不另建业务规则。内容真源、阅读器和维护约定见[项目手册](../../manuals/README.md)。

### 工作台与统计看什么

| 预览 | 核对重点 | 事实边界 |
| --- | --- | --- |
| 效能工作台 | 先选目录、诊断、核验或阅读样板；比较状态，完成一次操作，再按“真实页面核对”中的任务独立验证消费者；整体预览核对导航与跨页任务 | 统一样板使用共享组件，整体预览使用同一 HTML；二者只改变隔离样例，不证明真实测试、部署或验收 |

## 如何维护 / Maintenance

1. **保留唯一来源**：本目录仅一份最新 HTML；不增加重复查看器、图片方案或历史版本目录。
2. **分清演示与事实**：固定日期和虚构数据仅用于审查；正式页面以 API、权限、状态、共享组件和实际证据为准。
3. **同步相关内容**：同时核对设计稿、说明、共享实现和受影响的浏览器场景。
   打印中心的 `printTemplates` 内容快照逐项对齐正式 `printTemplateCatalog` 的名称、用途和 `guide`；`devUIDesign.test.mjs` 守住内容同步，`dev-ui-design-print-template-guide` 浏览器场景核对选择、编号、只读、编辑返回、BOM 三种带值打印与收窄布局。
4. **核对帮助快照**：`web/src/dev-workbench/config/devUIDesign.test.mjs` 检查岗位内容同步及概览有效性；内容变化后复核交接、异常和完成条件。
5. **保留业务边界**：不放宽 API/RBAC、取消/冲正、未保存保护或 Workflow 与事实的区分。快照检查不自动证明后端逻辑一致。

设计入口不写入业务，也不证明发布或客户验收；实现范围由设计说明、代码和测试共同核对。

# 交互设计 / UI Interaction Design

本目录维护 ERP 与效能工作台的界面结构、视觉与操作合同。[index.html](index.html) 保留唯一的完整流程交互稿；控件设计和工作台统一页面样板直接调用共享 React 组件，核对当前实现与组合方式，不复制第二份 HTML。修订由 Git 追踪；Figma 仅作设计参考。参考方案的采纳与维护边界见[设计资产维护](设计依据.md#设计资产维护--design-maintenance)。

| 要核对什么 | 入口 |
| --- | --- |
| 页面布局、控件、状态和完整操作路径 | [最新可交互 HTML](index.html)，或工作台“交互设计” |
| 页面职责、状态、数据及验收行为 | [交互设计说明](交互设计说明.md) |
| 为什么这样安排布局和动作 | [设计依据](设计依据.md) |
| 当前共享控件 | 工作台“交互设计 → 可交互设计 → 控件设计” |
| 效能工作台页面组合与任务验收 | 工作台“交互设计 → 效能工作台 → 统一页面样板”，规则见[统一页面样板](交互设计说明.md#workbench-patterns) |
| 两端界面值的含义、条件变化与布局原因 | 工作台“交互设计 → 设计说明 → 工作中心” |

共用反馈的三个操作入口：[设计说明的弹窗图解](/__dev/ui-design?view=specification&topic=dialogs)、[设计依据的结构与留白](/__dev/ui-design?view=rationale&topic=dialogs)、[真实控件演示](/__dev/ui-design?page=controls)。目录包含组件选择、弹窗结构与尺寸、Toast 与反馈选择、提交与恢复、关闭与焦点；每个主题链接规范和对应阅读入口。

演示使用共享组件与隔离本地状态，可切换成功、失败、结果未知，重试或重置。附件仅选择本地文件、不上传；CSV 与 HTML 打印稿在浏览器本地生成和下载，不写业务数据；讲解参数不写外观偏好。规则、设计表达、实际运行和业务验收分别核对。

## 怎样阅读 / Reading

1. 打开 `/__dev/ui-design`，选择“设计说明”或“设计依据”。
2. 在可搜索目录中选一个图解主题，点击图中区域、调整滑块或操作虚构样例。
3. 切到“规范原文”，按章节核对完整规则；比较看表格，顺序看编号，关系看图。
4. 用上一 / 下一主题继续阅读；目录可收起，正文独立滚动。
5. 复制链接、刷新或前进后退时，恢复阅读方式、主题、章节及搜索词。

| 图解内容 | 维护方式 |
| --- | --- |
| 页面骨架、间距、平面层次、文字对齐 | 复用当前主题变量；样例不写入账号偏好 |
| 下钻返回、表单容器、失败恢复、数据来源、窄屏排列 | 关系图直接读取正式说明 |
| 完整页面操作 | 继续使用同一份 HTML |

## 预览入口 / Previews

页面预览支持隔离浏览、全屏、重置演示及下载同一份 HTML；控件设计直接使用共享组件，在主内容区单独阅读和操作。生产管理可从预览选择框或 `page=production-hub` 直接进入，与业务界面侧栏中的生产管理使用同一模块。

切换页面入口时重新创建对应预览；切换到设计说明、设计依据或控件设计后返回同一入口，保留已打开的演示状态。岗位帮助的全屏切换与布局重绘保留未提交的搜索词，搜索、清空和内容导航仍按各自动作更新查询。预览须收到当前设计稿的渲染就绪确认；标签页恢复可见时重新核对布局，隐藏期间暂停就绪计时。初始化失败、布局不可见或可见后 12 秒内未就绪时显示重载入口，不持续留白。点击“重新加载预览”或“重置演示”会清空当前演示状态。预览加载与恢复只在浏览器本地执行，不写业务数据。

| 预览 | 地址 | 重点内容 |
| --- | --- | --- |
| 业务界面 | `/__dev/ui-design` | 单据、列表、表单与来源下钻 |
| 生产管理 | `/__dev/ui-design?page=production-hub` | 生产订单、生产执行、生产记录、异常处理四入口；任务直达与返回合同见交互设计说明 |
| 任务处理 | `/__dev/ui-design?page=task-handling` | 任务中心与业务页就地办理、工程整页编制、审批退回、入库确认与结果；BOM 版本操作、三种打印及主要业务动作共用同一份稿 |
| 工作中心界面说明 | `/__dev/ui-design?view=specification&topic=task-cards` | 电脑与手机共用内容，按需切换；值的含义、条件差异与布局原因一次解释一处 |
| 手机版任务 | `/__dev/ui-design?page=mobile-tasks` | 任务管理内的待办、已办、流程跟踪；流转详情、当前任务办理与返回 |
| 效能工作台 | `/__dev/ui-design?page=workbench` | 四类共享页面样板与状态操作；“整体交互预览”保留总览、工具导航、证据详情与操作确认 |
| 登录页 | `/__dev/ui-design?page=login` | 身份、工作方式、验证与失败修正 |
| 岗位帮助 | `/__dev/ui-design?page=help` | 办理概览、图解和参考手册；也可从稿内“系统与帮助 → 帮助中心”进入 |

业务界面和手机版任务的“状态模拟”使用共享 `AppSelect`，选中后保留用途与状态，清空后恢复正常内容并保留选择入口；切换预览入口或重置演示会清空选择。业务界面提供“切页等待”，手机提供首次加载、切换栏目、刷新、空白和失败状态，预览内重试或清除条件后同步当前状态。“页面状态样例”可进入直接使用共享组件的控件演示。HTML 保留单份、独立下载的场景表达，手机骨架仅使用现有卡片布局的静态占位；组件动画与真实几何在控件样例中核对。

业务界面的“边界压力”“压力 · 读取较慢”“压力 · 读取失败”共用正常列表与详情。实际记录、字段极值、明细、关联和附件的规模及操作见[压力状态说明](交互设计说明.md#boundary-preview)；表格工具中的“弹窗边界”直接打开可搜索、分页和返回的真实样例详情。

### 控件设计看什么

1. 与业务界面、任务处理、手机版任务、效能工作台、登录页、岗位帮助同级切换，入口为 `/__dev/ui-design?page=controls`。
2. 左侧搜索并选择组件选用、业务表单与明细、来源选择、基础输入、日期与时间，以及已有的弹窗与反馈、页签与视图、筛选与搜索、按钮与动作、页面状态、数字提醒。
3. 右侧只展开当前示例，结合三步核对和“场景 / 设计选择 / 原因”表阅读；共享实现按需查看。
4. 目录选择与关键词随 URL、刷新及前进后退恢复；无结果时清除搜索会将焦点交回搜索框，可直接继续输入。浅深主题仅影响样例，重置演示只重置当前展示区域。

“组件选用”（`/__dev/ui-design?page=controls&control=components`）直接读取[正式组件入口](../../engineering/前端实现与交互约定.md#组件复用与使用入口--shared-component-entrypoints)，覆盖通用、业务组合和打印专用组件；打印组件从该处进入打印专题。

“业务表单与明细”（`control=business-form`）操作正式整页表单、分区、明细和长文本组件，覆盖校验、增删及空态、离开保护和保存重试；“来源选择”（`control=source-picker`）操作正式来源选择弹窗，覆盖搜索、跨页选择、停用限制、取消与重开、加载、空列表和失败恢复。两类按需加载，只操作本地虚构记录。组件选用和各分类提供同源的真实页面入口与核对任务，在新标签页打开并沿用业务权限；独立工作台的业务站点复用部署目标。

“日期与时间”（`control=dates`）直接使用 `DateInput`、`DateTimeInput`、`DateRangeFilter`，操作即时选值、清空、快捷截止及倒置范围。基础输入通过 `AppSelect` 演示用途标签、清空和空态；筛选由 `FilterSelect` / `SelectFilter` 统一空条件，规则见[下拉选择与清空](交互设计说明.md#select-controls)。

“筛选与搜索”（`control=filters`）可切换电脑和手机，直接操作共享 `FilterChip`、`HorizontalScroll` 与搜索。手机展示 32px 可见外观、至少 44px 点击区和数量底色，窄屏在同一行滑动；完整手机稿同步相同外观，筛选面板仍保留可换行的 36px 底色选项。

### 岗位帮助看什么

| 阅读任务 | 展示方式 |
| --- | --- |
| 交接与异常 | 业务链，在同一位置显示办理概览 |
| 连续办理 | 编号步骤；点击查看当前步骤、完成结果或恢复 |
| 简单查询 | 短路径；窄屏由同一场景数据生成纵向编号 |
| 局部操作位置 | 字母标注，联动对应示意 |
| 查字段、公式、条件与边界 | 直接进入“业务手册”，包含通用阅读、岗位交接、24 个业务页及工程用料专题 |

“操作图解”和三册手册共用一层导航与全文搜索，可直接进入。图解首页按岗位推荐，目录按业务模块分组；桌面目录与正文独立滚动，手机按需打开目录抽屉。三册按账号权限提供在线阅读，统一章节卡片、章内导航和前后章入口，并通过“下载手册”菜单下载当前可读整册的 HTML / Markdown；可按任务、字段、状态、别称或问题查找。

工程用料审批与采购生成有教学图解；正式帮助入口为 `/erp/help-center`，内容来自当前共享帮助定义与正式手册，不另建业务规则。内容真源、阅读器和维护约定见[项目手册](../../manuals/README.md)。

## 如何维护 / Maintenance

1. **保留唯一来源**：本目录仅一份最新 HTML；不增加重复查看器、图片方案或历史版本目录。
2. **分清演示与事实**：固定日期和虚构数据仅用于审查；正式页面以 API、权限、状态、共享组件和实际证据为准。
3. **同步相关内容**：同时核对设计稿、说明、共享实现和受影响的浏览器场景。
4. **核对帮助快照**：`web/src/dev-workbench/config/devUIDesign.test.mjs` 检查岗位内容同步及概览有效性；内容变化后复核交接、异常和完成条件。
5. **保留业务边界**：不放宽 API/RBAC、取消/冲正、未保存保护或 Workflow 与事实的区分。快照检查不自动证明后端逻辑一致。

设计入口不写入业务，也不证明发布或客户验收；实现范围由设计说明、代码和测试共同核对。

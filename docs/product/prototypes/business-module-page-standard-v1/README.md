# 业务模块标准页原型 / Business Module Page Standard Prototype

本目录保存业务列表页骨架和条件式协同入口样板。它定义页面级信息层次，不重复业务表单、只读详情、局部动作或完整任务处理流程。

## 文件与责任

| 文件 | 责任 | 状态 |
| --- | --- | --- |
| `index.html` | 标题摘要、业务工作台、当前记录操作条、主表和分页。 | To Implement |
| `task-collab-entry-v2.html` | 仅显示当前选中记录的真实关联待办；无记录或无待办时不渲染。 | To Implement |
| `images/direction-*.png` | 三种早期协同入口方向，只作 Draft / Comparison 证据。 | Draft / Comparison |

## 页面口径

- 标准页以业务对象为中心：标题区只放 2–4 个稳定计数，筛选、导出、列顺序、新建和当前记录动作收口在业务工作台。
- 未选择记录时当前操作区显示“请选择一条记录”；选择后保留固定动作目录和顺序，只改变禁用态及原因。未授权动作才隐藏。
- 单击行选择；双击进入编辑或主操作 Modal。新建、编辑由业务表单样板负责，只读完整信息由详情 Modal 样板负责，不另做详情抽屉。
- 聚合单据可在首列展开前 5 条只读明细；“查看全部”进入详情 Modal。展开不改变选择，也不承载编辑、过账或状态动作。
- 页面只保留真实共享入口。状态规则说明、危险确认和列顺序的弹窗细节统一由 `action-modal-drawer-standard-v1/index.html` 表达，本页不再复制一套生命周期弹窗。
- 页面不提供通用批量删除、回收站或恢复。对象只展示正式业务规则允许的启停、取消、关闭、归档、冲正或调整动作。

## 协同入口边界

- 只有页面存在真实任务关联且已选择一条记录时，才查询该记录尚待处理的任务；没有待办时整个入口隐藏。
- 跨记录、跨模块的待办、阻塞、到期和交接回到任务中心；本组件不复制任务看板。
- 协同任务处理只改变协同状态。库存、质检、出货和财务结果仍在对应业务页面办理。

## 落地与验收

- HTML 是交互契约，不复制进生产代码；运行时继续复用共享列表布局、业务 Modal、正式路由、权限和主题 token。
- `index.html` 与条件式协同入口保持 `To Implement`，直到运行态布局、浏览器回归和人工确认均有当前证据。
- 桌面和窄屏都应保留标题、主筛选、当前记录动作和至少一部分主表；动作菜单可查看禁用原因，页面无横向溢出。
- PNG 方向图不进入当前设计，也不作为业务规则或实现证据。

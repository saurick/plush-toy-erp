# 局部动作弹窗样板 / Action Modal Standard

本目录保存后台局部动作弹窗的 `待实现 / To Implement` 标准样板。目录名中的 `drawer` 是历史路径；当前责任是局部动作 Modal，不再承载业务对象新建、编辑或完整单据补录。

## 文件与唯一责任

| 文件 | 责任 |
| --- | --- |
| `index.html` | 来源行选择、状态规则说明、列顺序和危险动作确认。 |

完整业务表单由 `business-form-page-standard-v1/index.html` 统一表达；完整只读详情由 `business-detail-page-standard-v1/index.html` 表达。本样板不得再复制两者的字段和明细编辑结构。

## 交互口径

- 来源选择器只筛选和勾选候选来源行，展示来源数量、已处理数量、剩余数量、状态和不可用原因；导入后回到父业务表单补齐本单字段。
- “清空筛选”和“清空已选”分别操作候选条件与选择集合。筛选、翻页和不可用行变化不得静默丢失已选摘要。
- 主业务弹窗最多再打开一层来源选择器；复杂预检继续在来源选择器内部完成，不叠第三层。
- 列顺序只表达列表偏好。业务明细顺序仅在对象已有受控重排命令时复用此交互，不把列偏好当作业务事实。
- 状态规则说明只解释主数据停用、源单取消或关闭、事实取消或冲正等对象差异，不提供通用删除或回收站。
- 危险动作使用小型确认框，明确当前对象和影响；未完成后端规则、权限、引用检查、审计与测试时不展示删除或恢复入口。

## 边界与验收

- 原型保持 `To Implement`，不替代 API、usecase、RBAC、schema、migration 或运行时测试。
- 不在这里复制业务表单、业务详情或完整任务处理流程。
- 四种局部弹窗可从状态切换条打开；标题、宽度、底部动作和初始焦点符合各自任务。
- 来源选择器在桌面和移动视口均可看到分页、已选摘要、两个清空动作及不可用原因。
- 弹窗打开时背景不可交互，`Escape`、关闭按钮与焦点恢复可用；浅色、暗色和窄屏不横向溢出。

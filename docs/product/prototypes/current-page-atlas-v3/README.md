## 目标

本原型按当前仓库真源提供两类能力：

1. 当前页面地图：盘点当前 56 个可见页面或路由模式，支持按范围、关键词和页面分组筛选。
2. 共享交互样板：用销售订单中性样例演示列表筛选、单选记录、分页、列设置、显式详情、当前记录关联任务、表单弹窗、状态恢复和键盘交互。

“56 个页面”只表示当前路由盘点，不表示已经为 56 个页面分别制作了完整业务原型，也不证明页面已经发布、可交付或通过客户验收。

## 交付特性

- 单文件、离线、无 CDN 和无构建依赖。
- 页面搜索、范围筛选和 `Ctrl / Cmd + K` 命令面板。
- 浅色 / 暗色主题和窄屏布局。
- 业务对象使用 Modal，Workflow 任务使用侧边处理面板。
- 加载、空数据、错误、无权限和长文本状态实验。
- Workflow 完成不等于库存、出货或财务事实生效。

## 当前设计边界

- 页面名称和路径以当前菜单、路由与业务模块配置为准。
- 不包含真实客户公司名、客户资料或客户品牌。
- 所有金额、日期、客户和任务均标记为中性模拟数据；不展示无来源 KPI 或趋势图。
- 页面地图和交互样板分开，不把一套通用列表渲染器冒充 56 套页面设计。
- 无权限状态下新建、详情和任务动作全部不可执行。
- 关联任务只从当前选中记录的 `tasksByRecord` 读取；无任务记录不显示处理入口。
- 列设置、筛选、分页和恢复按钮都有真实的本地状态变化，不保留假按钮。
- 弹窗、任务面板和命令面板提供打开焦点、Tab 圈定、Escape 关闭和触发点焦点返回。
- 单文件不与宿主页面跨窗口通信，也不接生产 API、后端或 RBAC 写入口。

## 使用方式

直接打开 `index.html`，或在本地开发环境访问 `/__dev/prototypes`，选择“当前页面地图与交互样板 v3”。当前查看器会把整份 HTML 作为隔离的 `srcDoc` 加载，因此本文件必须继续保持自包含。

建议评审顺序：

1. 在“页面地图”核对页面名称、路径、范围和业务边界。
2. 在“交互样板”验证筛选、单选、分页、显式详情和当前记录任务。
3. 在“状态实验”切换加载、空数据、错误、无权限和长文本。
4. 使用键盘打开表单、任务或命令面板，检查 Escape 和焦点返回。

## 正式吸收边界

- 本资产保持 `To Implement`；未经用户明确确认，不晋级 `Current`。
- 正式页面继续使用当前 API、RBAC、客户 effective session、菜单和 theme token，本原型不提供新的运行时真源。
- 任务模拟只改变原型内存状态，不写 Workflow；任务完成也不写 Fact。
- 新建和保存只产生原型提示，不写业务数据。
- 页面矩阵变化时应先修改当前路由、菜单或业务模块真源，再同步本原型和合同测试；不要反向用本原型修改正式能力。

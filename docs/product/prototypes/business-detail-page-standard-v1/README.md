# 业务详情弹窗样板 / Business Details Modal Standard

目录名保留历史的 `page` 路径，当前资产责任已经收敛为只读详情 Modal，并与运行时共享 `BusinessDetailsModal` 结构对齐。

## 文件与唯一责任

| 文件 | 责任 |
| --- | --- |
| `index.html` | 只读标题、说明、字段描述表、完整明细及加载 / 空 / 失败状态。 |

## 当前结构

- 从业务列表当前记录打开同一套宽 Modal，不再复制侧栏、菜单或独立详情页外壳。
- 字段按桌面三列、中屏两列、窄屏一列显示；缺值统一显示 `-`，不由原型补造事实。
- 完整明细按卡片展示标题、摘要和只读字段，超过 10 条时分页；同时覆盖加载中、空明细和加载失败后重试。
- 底部只保留“关闭”。编辑、状态变化、打印、附件维护和协同处理回到各自正式入口，不在详情 Modal 再造动作区。

## 边界与验收

- 本资产保持 `To Implement`；运行时真源是共享 Modal 组件、页面列配置和明细加载函数。
- 不替代业务表单、局部动作弹窗、任务处理流程、API、权限或业务事实。
- 打开后背景不可交互；关闭按钮、`Escape`、焦点陷阱和触发点恢复可用。
- 明细状态切换只用于原型评审，不是运行态业务字段。
- 桌面、平板和手机视口无横向溢出，浅色与暗色均可读。

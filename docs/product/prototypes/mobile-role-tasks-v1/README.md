# 岗位任务端 v1 列表基线 / Mobile Role Tasks v1

本目录只保留岗位任务端任务列表视觉基线和早期视觉资料。详情、处理与结果回执的当前交互由 `mobile-role-tasks-v2/index.html` 唯一定义。

## 文件与责任

| 文件 | 责任 | 状态 |
| --- | --- | --- |
| `implemented-reference.html` | 任务列表的紧凑顶部、显示设置、筛选、分批展开、局部刷新反馈和任务卡片选择。 | Current（仅任务列表样式，不含导航） |
| `images/*.png` | 早期列表、详情和工作台视觉方向。 | Draft / History / Evidence |

`implemented-reference.html` 不再保留旧详情页、原因面板、动作栏或提交脚本。选择任务后的“查看任务 → 处理任务 → 结果回执”，以及完成后恢复列表筛选、分页、滚动和焦点，全部由 v2 样板负责。

## 列表口径

- 默认展示当前岗位的待办，并提供全部、审批、风险和超时筛选；没有审批权限时不展示审批筛选。
- 列表按需展开更多，不伪装成已经加载全部数据；刷新时保留任务、筛选和当前页签，只更新刷新反馈。
- 顶部保持标题、当前岗位和明确的刷新按钮；搜索与统一筛选入口同排，待办 / 已办保留为任务内视图。高频分类保留一行，排序与任务状态在紧凑筛选面板中使用分段选择，避免多排控件挤占列表。
- HTML 通过按钮演示局部刷新反馈；真实页面的下拉手势、加载失败恢复和请求保护以 [移动端岗位任务页改版](../../移动端岗位任务页改版.md) 与浏览器回归为准。
- 待办卡片只展示岗位判断下一步所需的标题、来源、业务摘要、状态和截止时间。
- 点击卡片只表达“选中并进入 v2 流程”的交接，不在 v1 内执行完成、阻塞、退回或催办。

## 边界与验收

- `Current` 只覆盖 v1 列表壳；PNG 不是当前交互、权限或业务结果真源。
- 列表与 v2 使用同一任务身份；不得从展示字段推断具体经办人。
- 手机窄屏无横向溢出，底部导航固定可用；筛选、展开、刷新、返回页签与焦点状态可恢复。

运行时底部导航已按权限合并为“任务 / 风险 / 我的”，有进度读取权限时增加“进度”；待办和已办在任务内部切换。HTML 中的旧导航仅保留为原始视觉参考，当前导航与进度行为以[页面动作规则](../../业务数据生命周期与页面动作规则.md)和浏览器回归为准。

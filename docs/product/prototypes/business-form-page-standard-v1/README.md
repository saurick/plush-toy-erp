# 新建 / 编辑业务表单样板 / Business Form Modal Standard

本目录保存宽业务 Modal 的 `待实现 / To Implement` 样板。当前以销售订单为代表对象，对齐运行时 `SalesOrderForm`；其他业务对象只复用共享 Modal、字段布局和明细模式，不机械复制销售订单字段。

## 文件与责任

| 文件 | 责任 |
| --- | --- |
| `index.html` | 销售订单新建 / 编辑表单、附件、订单行、校验、来源切换和只读评审状态。 |

只读完整信息由 `business-detail-page-standard-v1/index.html` 表达；来源选择器、列顺序、状态规则和危险确认由 `action-modal-drawer-standard-v1/index.html` 表达。本样板不再复制这些局部弹窗的内部流程。

## 当前结构

- 使用运行时宽度 `min(1720px, calc(100vw - 96px))`。新建与编辑复用业务表单 Modal；只读查看复用同一视觉骨架但由详情入口打开。
- 主字段按运行态分为“订单与客户、联系人与负责人、结算条件、交付与收货、附件与其他说明”。客户、联系人和结算条件可从主数据带出，本单可覆盖的快照继续在本单维护。
- 订单行包含 SKU / 产品来源、带出产品 / 单位、单位、订单数量、单价、金额、计划交付日期和备注。
- “从 SKU 库添加”只打开第二层来源选择器；“产品顺序”只调整稳定订单行顺序。复制行创建新草稿行，移除行不等于删除已生效业务对象。
- 更换 SKU 时只更新产品、颜色、默认单位等来源字段；数量、单价、金额和交付日期不被静默覆盖。清空来源时对应来源摘要必须清空。
- 通用底部动作只有取消和保存。不存在跨业务对象通用的“重置整表”正式动作。

## 运行与事实边界

- 原型状态切换只用于评审新增、编辑和只读展示，不是运行态字段。正式模式来自打开入口、记录状态和当前权限。
- 保存前的必填、日期、数量精度、金额、来源资格和版本校验仍由正式表单与后端 usecase 共同守住。
- 附件选择不等于上传成功；只有业务对象保存和附件上传均成功后才建立正式关联。
- 本样板不创建库存、质检、出货、财务或任务结果，也不替代 schema、API、RBAC、migration 或测试。

## 验收关注点

- 五个字段分组、附件和订单行在桌面可扫描；窄屏改为单列且无页面级横向溢出。
- SKU 来源、带出摘要、复制行、移除行、产品顺序和统计入口位置稳定；订单行内部横向滚动不推宽 Modal。
- 必填错误能聚焦首个缺值；只读时全部变更入口和保存禁用。
- 打开后焦点进入真实控件，Tab 留在 Modal 内；关闭按钮、取消和 `Escape` 都恢复原触发点。
- 浅色、暗色、校验态、禁用态和附件空态均可读。

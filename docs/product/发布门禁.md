# 发布门禁 / Release Gates

本文只定义“什么证据可以支持什么结论”，不复制 QA 脚本编排、客户页面数量、单次测试结果或目标环境回执。当前命令以 `scripts/qa/README.md`、部署文档和脚本 `--help` 为准。

## 结论

发布不是一个“通过 / 不通过”总开关。代码合同、本地验证、远端 CI、不可变制品、目标环境发布和客户验收必须分别绑定同一版本，并分别报告。

```text
代码实现
  → 本地验证
  → 远端 CI
  → 不可变制品
  → 目标环境发布与读回
  → 真实岗位验收
```

前一层绿色只是后一层的输入，不自动证明后一层已经完成。

## 分层门禁

| 层级 | 必须绑定 | 最低证据 | 不能证明 |
| --- | --- | --- | --- |
| 代码合同 | 当前 diff / commit、schema、migration、usecase、RBAC、UI 和正式文档 | 受影响测试、静态守卫、生成零漂移和审查结果 | 已提交、已推送或已发布 |
| 本地质量 | 同一工作树或 clean commit、明确执行数和零意外 skip | `affected` 计划及与风险匹配的定向、fast、full 或 strict 结果 | 远端 CI、目标数据库和客户环境 |
| 远端 CI | push 后的精确 commit | required jobs 对同一 commit 绿色终态 | 制品已生成或目标环境已更新 |
| 不可变制品 | 精确 commit、镜像 digest / content ID、SBOM、migration 序列和配置输入 | manifest、校验和、加载后身份读回与 secret scan | active customer revision 或业务可用 |
| 目标环境 | 目标资源、制品、migration、active config、备份和回滚点 | preflight、串行 migration、health / ready、身份读回、登录与业务 smoke | 客户岗位已经接受 |
| 客户验收 | 固定版本、真实账号、已确认数据和业务结果 | 岗位逐项办理、异常恢复、打印实物和签收记录 | 后续版本仍然成立 |

失败停在当前层。不得用旧 commit、旧镜像、旧 active revision 或历史验收拼接当前发布结论。

## 发布前必须守住

- 工作树和提交范围可解释，其他任务的 WIP 不进入制品。
- schema 变更已经完成 Ent / Atlas 生成、migration、fresh / upgrade 与目标流程核对。
- Workflow task done、ProcessRuntime node completed 和 Fact posted 仍然分层。
- 后端继续校验 RBAC、模块、来源读取、责任池、状态、版本、幂等和数据范围；前端隐藏不构成门禁。
- 客户配置只能收窄 Product Core；真实客户缺 active revision 时失败关闭。
- 目标机只加载受控制品，不现场构建；发布前保留可恢复备份和明确回滚点。
- 日志、manifest、报告和浏览器输出不包含 Secret、完整 token、客户原始资料或不必要的个人信息。

## 选择验证

开发期先运行：

```bash
bash scripts/qa/affected.sh --plan
```

按计划执行所需定向检查，并显式补充 `affected` 不能代选的 schema 生成、真实数据库、浏览器、备份恢复或目标环境检查。`full`、`strict` 和 `prepare-push` 的当前阶段顺序、锁与回执以脚本说明为准，不在本文复制。

业务主链和证据范围见[ERP V1 主链验收计划与证据边界](ERP-V1主链验收计划与证据边界.md)，测试层级见[自动化测试策略](自动化测试策略.md)，目标环境步骤见[部署约定](../部署约定.md)和 `server/deploy/README.md`。

## 停止条件

- 无法确定目标环境、制品身份、migration 状态、active revision 或回滚点。
- 执行结果为零测试、存在失败或意外 skip，或者结果绑定的是另一工作树 / commit。
- 目标数据库归属不明，或准备绕过项目 migration、备份、串行锁和读回流程。
- 需要 force、改写历史、清理客户数据、删除 volume 或扩大授权范围。
- 当前只具备本地证据，却准备宣称已部署、已恢复或客户已验收。

## 维护规则

- 本文只在证据层级、发布边界或正式入口变化时更新。
- 单轮测试计数、commit、镜像、迁移号、目标地址和客户签收进入对应回执或受控交付资料。
- 脚本参数、阶段和命令变化只更新脚本及其 README，不在这里形成第二套编排。

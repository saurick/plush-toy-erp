## 当前产品形态

同一套 Product Core 按客户独立私有化部署。客户差异优先进入配置、权限、菜单、字段、打印与导入适配；当前不实现 SaaS tenant、license 或计费后台。对象与事实归属见[架构入口](../architecture/README.md)。

## 维护规则

能力台账只随能力边界、状态或关键阻塞变化更新；客户启用、发布和 UAT 记录在客户交付资料。文档增删与职责变化统一按[索引同步规则](../README.md#索引同步--index-sync)处理。

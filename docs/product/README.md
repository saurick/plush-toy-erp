## 当前产品形态

当前是单仓库、单客户独立数据库的私有化部署 Product Core。客户差异优先进入配置、权限模板、菜单、字段、打印、导入适配和部署资料；当前不实现 `tenant_id`、license、billing 或 SaaS 运营后台。若未来商业形态改变，应基于真实客户和运维证据重新评审，而不是保留一套空转的 SaaS 计划文档。

## 维护规则

新增、删除、重命名或重分类长期产品文档时，同步本 README、`docs/文档清单.md`、引用和相关测试。能力台账只在产品能力边界、状态或关键阻塞实质变化时更新；客户启用、发布和 UAT 进入客户交付资料，不与 Product Core 状态混写。

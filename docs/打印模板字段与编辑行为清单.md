# 打印模板字段与编辑行为清单 / ERP Print Template Field Behavior

## 目的

说明当前毛绒 ERP 打印模板里“左侧工具怎么用”“右侧纸面怎么编辑”“PDF / 打印到底吃哪一份内容”这些稳定行为，避免把普通路由页、旧草稿恢复和当前窗口级编辑链路混为一谈。

本文只收口当前可见编辑行为，不解释完整实现分层；实现真源见[打印模板实现原理](打印模板实现原理.md)。

## 当前稳定行为

- 打印中心与五种模板的独立打印窗口共用系统主题：工具栏、侧栏、附图管理、主按钮和选中状态随主色及明暗模式变化，已打开窗口同步当前浏览器的外观设置。纸张始终保留白底和模板正文颜色，文字标红、图片标注等业务内容不受主题切换影响。

- 当前正式模板包括 `采购合同`、`加工合同`、`物料分析明细表`、`色卡`、`作业指导书`；当前运行时主入口是 `打印模板中心` 的默认样例、纸面预览和打印窗口入口，以及采购订单 / 委外订单 / 物料清单（BOM）页面按领域模型生成的打印草稿。委外订单带值打开加工合同和外发作业指导书；物料清单（BOM）页面带值打开物料分析明细表、色卡和内部 / 工程资料作业指导书。

  后续若要从其他领域页带值打印，必须先定义领域模型到打印草稿的字段映射。字段编辑、明细确认、图片槽维护和纸面微调都在独立打印窗口内完成。
- 打印只读取业务快照，窗口编辑不创建、确认、过账或反写业务事实。模板字段合同、模块门禁及接入要求统一见[新增模板](打印模板实现原理.md#7-新增模板--template-onboarding)。
- 打印中心默认样例属于 Product Core 通用样例，可使用 `本公司`、`示例供应商`、`示例加工厂`、`采购负责人`、`公司联系电话` 这类中性展示值，方便编辑页和纸面预览完整呈现；客户公司名、真实联系人、真实电话、真实地址、真实签字人和原始资料路径不得作为核心模板默认值。客户专属信息应来自业务草稿、客户配置包、客户打印模板或客户交付资料边界；从业务页带值打开打印时，真实业务缺失字段保持空白，不用打印中心样例兜底。
- 客户配置包可声明 `printTemplateDefaults` 作为甲方 party defaults 草案：当前先经过客户包 lint、开发态客户配置页和 runtime manifest 编译，再由后端 active revision 的 `customer_config.get_effective_session` 受控投影给正式前端；采购订单页的 `material-purchase-contract` 打印入口和委外订单页的 `processing-contract` 打印入口已消费该投影中的买方 / 委托方默认字段。

  销售订单打印模板仍未启用，供应商 / 加工方名称、联系人、电话和地址仍必须来自业务记录快照，不允许被客户包默认值覆盖。

### 快速清空

- 独立打印窗口提供 `手签留白` 动作。该动作只清空当前窗口草稿里的甲方签名和乙方签名，保留甲乙方日期、签字区版式、合同主体、明细、条款和模板末尾附图，便于双方打印后手写签字。该动作不代表电子签署、审批通过或业务事实过账，也不会修改领域记录、模板配置、后端事实或其他窗口草稿。
- 独立打印窗口提供 `空白模板` 动作。该动作只清空当前窗口草稿里的字段值、明细行值、合并状态和模板末尾附图，保留模板结构与合同条款。该动作不会修改领域记录、模板配置、后端事实或其他窗口草稿。

### 草稿保存与恢复

- 弹窗打开主路径是直接进入 `/erp/print-workspace/:templateKey?...&state=:stateID` 形式的 React 工作台 URL；`state` 用来隔离当前窗口草稿。打印入口始终检查有效登录会话；`/print-window-shell.html` 只提示重新打开，不再读取旧窗口缓存。
- 草稿按当前账号、客户、配置版本、模板和窗口隔离，在 IndexedDB 中异步保存；顶部显示真实保存状态，失败可重试。刷新恢复以结构化草稿为准，不重复保存含图片的整窗 HTML。输出会等待当前草稿和纸面更新；尚未保存时离开页面会提示保护，强制退出不能保证排队中的输入。
- 原地编辑期间，草稿刷新保留当前字段的文字节点和光标；失焦后按各模板规则同步正文与草稿。输入法确认候选词不触发结束编辑；工程单行字段以普通 Enter 结束后，焦点恢复不会重新进入该字段。

### 工具、反馈与纸面输入

- 顶部合并标题、自动保存、显示比例和 PDF / 打印操作，纸面不再额外显示模式横栏。左侧“表格操作”默认展开，内部按明细行、单元格或色卡块分组，选择 / 删除占整行，插入及合并 / 拆分并排。进入选择后，数量和影响紧邻对应工具，组首按钮切换为“返回编辑”，不重复提供取消按钮；Esc 或收起表格操作会清除选择。字段值只在纸面编辑。

  产品图片使用缩略图、名称和上传 / 更换 / 清空入口；作业行选中后才显示行类型和图片工具。“末尾附图”标题带数量，与计算规则、模板内容默认收起，由各自标题直接展开。
- 恢复样例、手签留白、空白模板和行、单元格、色卡块、图片操作的结果放在所属工具分组下方；同一次操作只提示一次，后续操作替换旧结果，切换选择或继续填写纸面时清除旧提示。自动保存留在顶部工具栏；PDF 进度、成功和错误采用顶部悬浮提示，不在纸面上方占行或推移纸面。成功提示 4 秒后消失，进度随操作结束更新，错误保留到关闭、重试或继续编辑；关闭提示不会取消正在进行的输出。局部反馈自动展开所属工具组，只滚动左侧工具区，不改变纸面位置；所有操作提示均不进入打印或 PDF。
- 空字段在编辑屏幕统一显示“点击填写”，悬停和聚焦不改变显示时机，输入真实内容后隐藏。提示沿用字段的左 / 中 / 右对齐，窄格可在原框内换行，不撑开单元格；提示不是草稿字段值，也不会进入 PDF 或打印。合同签字日期在屏幕上使用标签右侧的完整值槽，清空后不随文字收缩；正式打印保留原有排版。全模板空值回归逐字段清空，在 75% / 100% / 125% / 150% 下核对聚焦、失焦和提示完整性，并检查打印不带出提示。
- 显示比例使用共享壳内的 Ant Design Select，明确固定字体、32px 高度、120px 宽度、6px 圆角、装饰箭头及焦点样式，不依赖宿主全局控件外观。支持适应宽度、75%、100%、125%、150% 和键盘操作；只改变屏幕浏览，不改变 PDF 和物理纸张尺寸。

桌面工作台按顶部工具栏和留白提示的实际高度分配剩余视口，工具区与纸面各自滚动，局部反馈不触发整页滚动。窄屏继续使用上下排列和页面滚动。合同条款标题在屏幕编辑时保留至少 4em 的空值输入槽，标题焦点框向外保留 3px，左右预留 4px，不用上下外边距撑高条款；默认加工合同的完整签字区仍应排入一张 A4，这些编辑间距不进入打印和 PDF。
- 五套正式模板都使用同一个模板末尾附图管理区：可一次多选图片，查看当前张数，向前 / 向后调整顺序或移除单张图片；每张图片还可选择 `自动 / 半宽 / 整行`，操作和排序都以原始逻辑图片为单位，超长图分成多段后也不会在管理区伪装成多张图片。
  - `自动` 默认把普通横图、方图和常规照片排成半宽，每行最多两张；明显纵向长图或横向超宽图独占整行。用户可按实际可读性手动切换为半宽或整行。
  - 同一半宽行的两张图片顶部对齐，各自保持原比例和自然高度；该行高度取两张中的最高值，下一行从最高图片下方开始。奇数最后一张保持在左侧。
  - 整行图片使用纸面可用宽度。超长图片会在添加时按打印页安全高度连续分段，输出时保持原顺序，避免一张长图被浏览器分页直接裁断。
  - 图片按打印宽度生成快照，不拉伸、不裁切，也不把低分辨率原图放大；在线 PDF 不再对这些末尾附图做第二次低清压缩。这里的“保持清晰度”是保持原比例和打印所需像素，不是无条件保存相机原文件字节。左侧会显示长图展开后的输出张数和预算问题。
  - 末尾附图不另设业务规则数量，但不代表无限资源：单次 PDF 的正文和末尾附图合计最多 32 张内嵌图片，并继续受浏览器处理 / 存储能力及服务端单图、总图片、HTML、CSS、DOM、请求体和输出大小预算约束。
- 两套合同的数量、单价、备注和条款都在纸面编辑；左侧结构工具作用于选定明细、单元格或条款条目。
- 单位和数量遵循[统一计量口径](product/业务公式与计算口径.md#计量单位与数量精度--units-and-quantity-precision)。计数单位只接受整数，码最多 6 位、千克最多 3 位；单位留白时不推断单位，已填数量按正数、最多 6 位小数检查。单价最多 6 位，超精度保留输入并在输出前给出行级提示，混合单位不生成数量总和。
- 采购合同和加工合同顶部统一只框住可编辑的字段值，字段名留在框外。连续切换字段时，后台 PDF 预热不会结束当前编辑；显式预览、下载和打印仍先收口当前输入。
- 采购合同和加工合同主表当前都按“整格输入”理解：点击表格里的实际内容块即可直接改当前格；选行模式开启后，点击明细行会只切换当前操作目标，不会顺手改动其它行。
- 右侧纸面默认不显示编辑边框；聚焦时统一显示当前主题主色的虚线和浅色底色。普通字段的焦点框向外留白，为中文文字和光标保留上下、左右间距；表格单元格统一显示内缩的整格焦点框，1px 虚线使用 -2px 偏移，保持在表格线内；直接编辑单元格或通过内层节点编辑时均只有一层框，点击区域仍覆盖整格。焦点样式由共享工作区统一维护，不改变文字位置、字段尺寸或打印排版。

  像物料分析明细表顶部“日期 / 毛向”和底部“审核 / 制表”、色卡顶部“产品编号 / 产品名称”、色卡页脚“制卡 / 日期 / 审核 / 复核”这类标签和值同格的区域，打印视觉按源 Excel 保持非格子排版，标签不进入编辑区；字段名文字和值文字按合同模板口径保持视觉对齐，右侧可编辑值槽保留稳定点击高度和宽度，不能只包住文字或退回过小点击区；长值仍在值槽内换行且不得横向溢出；打印和 PDF 不带出这些焦点样式。
- 空内容下继续按 Backspace / Delete 不会删除光标占位或改变对齐；删除最后一个字符后可直接重新输入，也支持原生撤销 / 重做。占位只用于屏幕编辑，不作为字段值保存；组合输入期间保留输入法管理的内容，结束后再恢复空值光标。此规则由工作区统一绑定，动态新增的编辑格也自动生效。
- 清空合同条款只清除文字，保留条款输入位置及其序号；删除条目才移除位置并重排编号。两种结果都随当前窗口草稿保存，刷新不会补回已删除条目。
- `上插一行 / 下插一行 / 删除当前行 / 选择明细行 / 选择单元格 / 合并选区 / 拆分当前 / 计算规则` 继续只作用于当前弹窗里的草稿，不会静默回写业务真源。
- `在线预览 PDF / 下载 PDF / 打印` 都以当前弹窗里的纸面 DOM 为输出来源，不再走第二套单独模板：
  - PDF 预览 / 下载前会先收口当前焦点输入，再把同一份右侧纸面主区域 DOM 快照交给后端 `/templates/render-pdf`。
  - 浏览器打印直接打印当前弹窗里的同一份纸面，不输出左侧工具区。
- 两套合同在内容仍落在单页 A4 内时，继续保持 `0` 物理页边距；一旦内容跨到第 `2` 页及后续页，浏览器打印与在线 PDF / 下载 PDF 会统一切到 `@page margin: 5mm 0 5mm`，给续页顶部和底部留出固定缓冲，避免正文贴页顶开始排。
- 右侧纸面舞台继续统一使用灰色背景；打印态会隐藏左侧工具区、顶部工具栏、公式面板和末尾附图管理区，只保留 A4 纸面及已排入纸面的附图。

五套模板在预览、下载和打印时都允许字段、部分明细和整行留白，保留当前纸面已有内容，不要求切换“空白模板”或补齐信息。“空白模板”仅用于快速清空当前草稿。已填写的数量和单价继续遵循计量与精度口径，零金额有效；图片加载与可用性、说明框溢出和输出资源预算仍须检查。字体和资源预算见[实现原理](打印模板实现原理.md#8-字体与输出预算--fonts-and-output-budget)。

五套模板及采购批量窗口在顶部工具栏下方共用一行轻提示：“当前有 N 处留白，将按当前内容输出；空白处可打印后手写补充。”计数与定位按字段用途覆盖可编辑业务内容，包含非表格信息和明细，不以是否位于表格中区分。

| 模板 | 留白计数与定位范围 | 排除范围 |
| --- | --- | --- |
| 采购、加工合同及采购批量窗口 | 合同 / 采购订单号、下单和回货日期、双方名称或单位、联系人、电话、地址，全部可编辑明细及每条正文条款；两套合同各有 11 个表头业务字段，一行明细全空均计 12 处，每条空条款计 1 处 | 双方签字、盖章、签署日期 |
| 物料分析明细表 | 公司、产品与订单信息、数量、备品、业务日期、设计师、备注、毛向及可编辑明细 | 制表、审核署名，列名 |
| 色卡 | 公司、产品编号与名称、材料名称、材料说明、部位、方法及制卡业务日期 | 制卡、审核、复核署名，图片占位 |
| 作业指导书 | 公司、产品、订单、版本、工序、工序日期、发放部门、设计师、步骤编号、步骤 / 段落正文及图片旁的文字说明，含可编辑续页正文 | 制表、审核署名，只读续页表头，图片占位 |

签字、盖章和签署日期继续不提醒；业务日期参与计数。有条目的合同分组名称属于可编辑业务内容，名称留空计 1 处，位于该组条目之前定位；没有条目的空组不进入纸面，也不计名称留白。固定标题、自动编号、列名、合计等非业务值、非编辑格和合并后隐藏格不参与。

首次点“查看留白”从整张纸最上面一行最左侧的留白开始。多处留白在首次查看后显示“第一处 / 上一处 / 下一处 / 最后一处”；首尾按钮直接跳转，上一处和下一处按纸面业务信息、明细、正文、页脚的顺序双向循环定位，双列区域按实际位置从上到下、同行从左到右。只有一处时只显示“查看留白”。填好当前字段后，数量和导航状态自动更新，双向定位仍按原字段位置继续查找，不跳过相邻留白；数量更新不打断输入。

补齐或移除所有留白后提示自动消失，再次出现留白或切换输出批次时从首处开始。提示不弹确认框、不禁用预览 / 下载 / 打印，不保存到草稿或进入输出正文；批量窗口只统计当前输出批次，按每份合同的表头、明细、正文顺序依次定位。窄屏下导航按钮可换行。

## 条目编辑

| 模板与对象 | 编辑入口与行为 | 编号与边界 |
| --- | --- | --- |
| 采购、加工合同条款 | 左侧“条款编辑”支持新增分组、修改分组名称、上下调序和删除分组；组内条目继续支持插入、调序、清空和删除。名称可在左侧或纸面修改，共用当前草稿；纸面编辑或留白定位同步当前组和条目 | 可见分组按一、二、三……连续编号，组内条目从 1 编号。最多 20 组、每组 100 条；已有超限内容保留并提示删减，不截断 |
| 采购批量合同条款 | 使用同一条款工具，显示当前合同；编辑和调序只影响当前合同 | 分组、编号和空组规则与单份一致；未选合同及其他批次保留原草稿 |
| 采购、加工合同及物料分析明细行 | 选择明细行后，除原有插删外可上移、下移和清空 | 涉及纵向合并时整块移动或清空，保留合并关系；已有明细最少行数规则不变 |
| 色卡块与色卡行 | 选择块或已存在的行后，可插删、上移、下移和清空 | 块只在所在左右栏内调序；清空块保留块与行位置，清空行保留该行 |
| 作业指导书正文行 | 选择行后可插删、上移、下移和清空；调序携带整行文字、图片和标注 | 编号行按标题 / 文本分组重新编号；删除组内全部条目后，该组空标题只保留在编辑页，PDF / 打印不输出；续页各自维护行顺序 |

“清空”保留当前条目及其位置，空业务字段继续计入留白并可定位；“删除”移除条目，对应留白同步从数量中移除。标题后仍有一条清空的条目时保留标题，只有真正删空的组才隐藏标题。增删、调序、清空或恢复模板后，留白导航从首处重新开始；继续填写则沿原字段位置查找下一处。

“新增分组”在当前组后插入，没有分组时创建第一组；自动选中新组并定位左侧名称输入，带一条空条目。新组的空名称和空条目分别计入留白，允许按当前内容输出。分组移动携带组内全部条目，重复名称可保留，选择按分组身份区分；删除分组移除其全部条目并选择相邻组。最后一组可删除，刷新不会补回默认分组，仍可通过“新增分组”重新开始。

组内条目删到零时，分组仍保留在左侧，名称可修改，并可通过“新增条目”恢复；该组标题不会进入纸面、PDF 或打印。所有组和条目的顺序、名称、空值及删除结果均随窗口草稿保存。采购批量窗口的操作只修改当前合同，不重新归并已编辑的合同。

条目操作、分组选项和结果提示均在纸面外。预览、下载与打印继续读取当前纸面，允许保留留白；操作按钮、留白提示和定位按钮不进入 PDF 或打印。所有编辑只保存到当前窗口，不回写源单、BOM 或其他业务事实。

## 当前模板差异

### 采购合同

- 中间采购明细区保留表格，合同头、条款和签字区按普通纸质合同排版。
- 工程用料审批自动生成的采购单，从采购明细读模型带入审批时冻结的产品编号、名称、来源订单和材料备注；已有单据与新单据采用同一口径，详见[订单采购边界](architecture/订单采购边界评审.md#bom-到采购需求)。打印重新读取材料与单位，包括已经停用但仍被单据引用的资料；缺少实际联系人、价格或交期时保持空白。
- 已审批的工程用料汇总表提供“打印本次采购合同（N 份）”，带入本次生成的全部采购订单，不受采购列表分页影响。采购列表通过表格勾选进行单份或批量打印，供零散补打。
- 本次选中的采购单按供应商编号和一致的合同条件自动归并；同名但不同供应商编号不合并。币种、付款、开票、交货、双方信息或条款不同则分开，清单说明原因。三张同供应商且条件一致的采购单输出一份合同，保留三张采购单的全部明细，每行继续显示原采购单号和产品订单号，不把相同材料行合并掉。
- 批量窗口默认全选，清单以供应商为主，显示包含的采购单数量、来源单号及已填数字的格式问题；点选合同可定位纸面，直接编辑或留白，也可取消本次不打印的合同。范围、选择、修改内容和当前批次均随窗口草稿保存，刷新后恢复；这些修改不回写采购事实，不放开已审批订单的业务编辑权限。
- 每次输出最多 `20` 份归并后的合同，超过时保留完整清单并明确展示各批范围；最后一批允许只有一份。一份合同允许自然续页，每份合同独立起页。预览、下载和打印均检查当前批次的已填数字、纸面及资源预算，字段或明细留白不阻断输出；同份超过 `300` 行时明确提示减少本次选单，不截断。批量不提供插删行、合并单元格或附图管理，需调整这些内容时使用单份工作台。
- `采购金额` 默认按 `数量 × 单价` 重算，但仍允许按合同快照手工改写金额列。
- 数量合计仅在所有有效数量行的单位一致时显示；不同单位保持逐行数量，合计栏不混加。同币种金额仍精确合计。
- 单位是打印草稿快照，不回写主数据。名称归一、数量精度、未知值处理与混合单位合计统一遵循[计量单位与数量精度](product/业务公式与计算口径.md#计量单位与数量精度--units-and-quantity-precision)；不得为统一纸面外观伪造来源单位。
- 行选择、插行、删行会同时维护当前行选择、合并块和合计，不再复制相邻行旧值生成新行。
- 采购明细当前支持原地矩形 merge / split：合并后只保留左上角内容，被覆盖格会清空；删除命中纵向 merge 时会按整块一起删除。

### 加工合同

- 加工明细纸面默认只渲染真实明细行，不再为了凑固定高度额外补两行占位空白行；需要新增空行时，必须通过 `上插一行 / 下插一行` 显式插入。
- 默认三行样例的明细、完整条款和签字区排在同一张 A4，保留原字号及手签留白；长合同允许条款按组续页，签字区整体跟随前文，避免单独占一页。
- 从委外订单带值生成加工合同时，明细行 `产品订单编号` 优先读取 `outsourcing_order_items.product_order_no_snapshot`，旧数据缺失时才回退到委外订单表头 `source_order_no`；该字段只作为合同逐行追溯快照，不新增销售订单外键，也不生成委外事实。
- 委外订单保存的甲方合同快照和乙方合同快照是加工合同主体信息真源；乙方单位、联系人、电话、地址和签约人不会在打开打印时拿当前加工厂档案覆盖。草稿提交和确认下单前会检查甲乙方必要信息、预计回货日期以及每条有效明细的加工项目。
- 明细金额默认按 `委托加工数量 × 单价` 带值；如合同快照已有确认金额，可在右侧纸面直接改写 `委托加工金额`。
- 原来固定两个纸样 / 图样槽位已并入五套模板共用的末尾附图数组；加工合同不再维护独立的两槽交互。
- 加工合同附件中显式标记为“合同附图”的 PNG / JPEG / WEBP / GIF 会在打开打印窗口时下载并冻结为 `appendixImages[]`；普通归档附件不会自动进入纸面。进入打印窗口后仍可调序、移除或继续加图，这些窗口内调整不回写业务附件。
- 条款区、签字区和表格区都允许在右侧纸面直接编辑，再回写当前草稿。
- 加工明细当前和采购合同一样支持原地矩形 merge / split；金额列可编辑，也可以参与合并展示。

### 工程资料模板


#### 产品图与来源读取

- 产品基础信息页可维护 0–2 张产品图。BOM 生成 `物料分析明细表` 或 BOM 来源 `作业指导书` 时，产品图 1 / 2 会分别冻结到当前草稿右上角的第一 / 第二图片位；只有一张时使用第一图片位，没有图片时保持空白，不用打印中心样例图兜底。打印窗口仍可对当前草稿图片做临时替换或清空，但不会反向修改产品主档。
- 图片工具在无图时显示“暂无图”，图片损坏或尺寸不可用时显示明确提示。纸面中的异常图片必须更换或清空后才允许 PDF / 打印输出；加载中的图片也不能被静默漏掉。无图的纸面图片位仍按模板留白，操作提示不进入正式打印件。
- 委外订单生成作业指导书时，只有全部有效产品明细归属同一个产品才自动带入该产品图片；多产品或产品关联不完整时不取首行猜测，仍打开打印草稿并提示人工核对 / 补图。

#### 物料分析明细表

- `物料分析明细表` 从物料清单（BOM）页面选中版本带值打开，服务板房工程部整理材料、部位、用量和工艺方式，打印给仓库对照发料；右上角产品图只是固定业务快照位，补充图改由共享 `appendixImages` 在模板末尾统一管理。两类图片都只进入当前打印草稿和 PDF / 浏览器打印输出，不替代业务附件归档。
- 物料清单（BOM）页面当前承接工程资料打印所需业务字段：表头维护 `来源订单号 / 订单数量 / 备品 / 制表日期 / 设计师 / 制表 / 审核 / 毛向`，明细维护 `片数 / 总用量含损耗 / 加工底料 / 加工方式`；这些字段随 BOM 版本和 BOM 明细保存、复制、JSON-RPC 回显和导出，并由 `物料分析明细表`、`色卡`、BOM 来源的 `作业指导书` 生成器读取。

  它们只服务工程资料、仓库发料对照和打印快照，不写采购、库存、出货、财务或 Workflow 完成事实。
- BOM 三种打印入口每次重新读取选中版本、产品、材料和单位，包含停用引用；读取失败或关联资料缺失时停止打开，不沿用页面旧选项。总用量与 BOM 页面共用算法：已有有效 `total_usage_snapshot` 时保留原值（包括零），输入变化使快照失效后才按订单数量、单位用量和损耗率重算。缺少订单数量且没有有效用量快照时保持空白。来源订单号、制表日期和材料信息缺失时不以 BOM 版本、当天日期或占位文字替代；业务物料明细的备注表头不附带样例纸样编号。
- `物料分析明细表` 的 `毛向` 属于顶部业务信息区字段，在顶部信息区左侧单独换行展示并可编辑，不和 `设计师` 横向挤在同一值槽；源 Excel 把 `毛向` 放在标题右侧靠近图片区的位置按当前口径视为源文件噪点，不照搬为运行时模板结构。
- `物料分析明细表` 顶部数量只固定显示字段名 `数量：`，单位和数值（如 `(PCS) 200`）在同一个紧凑值槽内编辑、保存和输出。生成或恢复草稿时，纯数字数量沿用模板默认 PCS 单位；已有单位或说明保留原文，明确清空时不补回单位或样例数量。
- `物料分析明细表` 支持按源 Excel 结构做当前窗口内的矩形合并 / 拆分：启用 `选择单元格` 后依次点击起点和终点，再执行 `合并选区`；合并后只保留左上角内容，被覆盖格会清空，`拆分当前` 只移除当前合并块。插入 / 删除物料行会维护合并块位置；删除命中纵向合并块时按整块删除，避免纸面残留半个合并区。该能力只影响打印草稿和当前纸面 DOM，不回写 BOM、材料、采购、库存或业务附件。
- 物料表的 14 列按源工作簿列宽比例排版，最窄列保留两字表头所需空间。材料类别、款号、单位用量等长表头按词组换行，颜色、单位、片数等短表头保持一行；自定义表头及手动换行随草稿保存，不被默认文案覆盖。

#### 色卡

- `色卡` 从物料清单（BOM）页面选中版本带值打开，服务板房工程部打印后线下贴布料 / 物料样本，交给仓库对色发料；色卡分块来自 BOM 明细 / 材料快照或当前草稿，不写材料主数据、采购或库存事实。打印中心默认样例的页脚保留 `制卡 / 日期 / 审核 / 复核`，其中 `审核 / 复核` 默认显示 `审核人 / 复核人`；从业务记录带值打开时，业务草稿明确为空的签核字段仍按空白处理，不用样例值伪造业务事实。

#### 作业指导书

- `作业指导书` 是工程 / 生产 / 品质共用的作业资料打印件，当前保留双入口：物料清单（BOM）页面选中版本时带产品、来源订单和 BOM 明细作业内容，服务内部工程资料准备；委外订单选中源单时带委外单号，并把加工厂、来源订单、回货日期、加工项目、工序和委外数量放进正文上下文，服务打印给加工厂执行。

  头六行按源工作簿保持 `产品编号 / 版本/版次 / 本页工序与日期 / 制表 / 设计师 / 审核` 的字段角色：G3 直接显示可编辑的简短本页工序（如 `车缝 / 手工`），H3 是独立可编辑的工序日期值槽；缺少明确来源时保持空白，不把全部 BOM 加工方式塞入 H3，也不拿 BOM 技术版本或委外回货日期冒充 `版本/版次`。

  公司名称在 A1:F2 合并格内水平、垂直居中，发放部门默认按原件显示 `生产部/品质部`。
- 作业指导书右侧头六行的字段名、工序名和字段值在各自单元格内水平、垂直居中；同一字体和字号下，字段名与工序名加粗，填写值使用常规字重。空值提示、输入中、有值、续页只读表头及 PDF 使用同一对齐方式；左侧发放部门、订单号、产品名称等长值仍保持靠左排版。
- BOM 三种工程资料模板的 `产品编号` 统一优先读取产品主档 `style_no`，再回退客户款号、来源产品编号和内部产品资料编号；委外入口只能沿用委外明细已经冻结的 `product_no_snapshot`，不拿当前产品主档覆盖历史源单。`产品名称` 只显示名称，不拼接内部款号或客户款号。产品编号和名称读取结构化字段，不拆解下拉选项的显示文字；字段本身的斜杠按原值保留。

  当前 Product Core 尚无独立的“纸样 / 作业指导书引用编号”字段：当客户原件编号与产品款号不同（例如跨款共用纸样），或委外源单未冻结业务款号时，业务草稿不会从文件名或产品名称猜造，需在当前打印窗口核对并编辑；正式自动带值要等该字段真源完成业务评审后再接入。
- 正文不再固定拆成 `裁床 / 刺绣 / 印花 / 车缝 / 备注` 字段，而是统一为可变正文行。正文行可切换为标题行、编号行或文本行，默认使用一致行高；编号行按最近的标题行或文本行分组从 `1` 重新编号，匹配源 Excel 中每个小模块独立编号的口径；只有编号行可维护行内图片。

  右上角支持 0–2 张产品图并在同一区域左右排列；产品图和编号行图片都只作为当前打印草稿图片槽，打印不表示委外、生产、质检或库存事实完成；生产进度、来料质检和加工环节页当前不直接生成作业指导书草稿。

#### 图片标注与撤销

- “标注当前行图片”内可切换图片，添加说明框或距离标注。标注列表始终显示类型、序号和文字摘要，同样的文字也能区分。说明框先使用右侧空位；图片区域不会随说明框增删而移动。空说明框显示“点击填写”，新增后直接在框内输入，支持多行和中文；侧栏只维护样式、尺寸和指向点，不重复提供说明文字输入框。文字编辑时方向键移动光标；拖动独立移动手柄或在手柄上使用方向键才调整位置。

  距离文字仍在侧栏填写，可在画布内拖动文字、用方向键或位置滑块沿线段两侧调整；文字按线段方向和自身尺寸留出间距，靠近画布边缘时使用可容纳文字的位置，端点不随文字移动。
- 标注列表支持逐个删除、勾选后批量删除及撤销最近一次删除；批量操作只作用于当前图片。撤销保留期间对其他标注的编辑，取消弹窗丢弃本次全部调整。空说明、缺少指向点或编辑中说明超框时，会定位到对应标注要求调整；保存后才进入打印草稿并自动保存，刷新和输出保留同一组标注。已有草稿在预览、下载和打印前也检查纸面说明框，文字超框时提示调整，避免静默裁字。

## 销售订单受理字段链路

销售订单受理是当前本地试用模拟优先闭环，但它不是当前正式打印模板。销售订单页已经接入客户配置 `sales_orders.default` 字段策略，列表和导出共用同一组可见列；打印侧仍不生成销售订单打印模板，也不把客户专属字段硬编码进 Product Core。

以下字段均未接销售订单打印；这里只核对页面、保存与导出链路。

### 销售订单号

**真源**：`sales_orders.order_no`

**采集与回显**：销售订单表单与详情使用订单号，不展示内部 ID

**列表与导出**：`订单号` 列，导出同列

**缺值与残值**：缺失时按页面空态显示，不从打印样例补造

### 客户

**真源**：`customer_id` + `customer_snapshot`

**采集与回显**：新建 / 编辑从客户主数据带出快照，切换客户时重带联系人和客户默认值

**列表与导出**：`客户` 列读取快照；缺快照但有关联时显示“客户已关联”

**缺值与残值**：不从模板默认客户名兜底，历史缺快照只显示既定关联提示

### 客户订单号 / 来源号

**真源**：`sales_orders.customer_order_no`，字段策略键为 `source_no`

**采集与回显**：表单维护客户订单号

**列表与导出**：`客户订单号` 列受 `sales_orders.default.source_no` 控制，导出跟随可见列

**缺值与残值**：字段被策略隐藏时列表和导出同时隐藏，不在打印模板绕过

### 业务员 / 跟单人

**真源**：`sales_orders.sales_owner`

**采集与回显**：表单维护文本值

**列表与导出**：`业务员 / 跟单人` 列，导出同列

**缺值与残值**：为空显示空态，不从登录角色或客户包推断

### 联系人

**真源**：`contact_snapshot`

**采集与回显**：选择客户后从联系人主数据带出；无联系人时清空联系人字段

**列表与导出**：`联系人` 列读取联系人快照

**缺值与残值**：切换客户会清空或替换旧联系人，避免残留上一客户联系人

### 付款条件

**真源**：`payment_method`、`payment_term_days` 与客户默认配置

**采集与回显**：表单维护并可从客户默认值带出

**列表与导出**：`付款条件` 列和导出使用同一格式化函数

**缺值与残值**：没有真源时显示空态，不从客户模板硬填

### 报价运费

**真源**：`sales_orders.freight_terms` + `sales_orders.quoted_freight_amount`；币种沿用 `sales_orders.currency`

**采集与回显**：选择“报价不含运费（另计）”后填写报价运费；切回“报价含运费”立即清空另计金额

**列表与导出**：`运费条件` 与 `报价运费` 分列展示并随可见列导出；含运费时显示“已含在单价”

**缺值与残值**：报价不含运费时保存即须明确填写金额，允许 `0`；历史空值不从出货实际运费或备注猜测回补

### 签约日期

**真源**：`sales_orders.order_date`

**采集与回显**：表单维护

**列表与导出**：`签约日期` 列，导出格式化日期

**缺值与残值**：非法日期由页面 / 后端日期合同拦截，不在打印层修正

### 计划交付日期

**真源**：`sales_orders.planned_delivery_date`，字段策略键为 `expected_ship_date`

**采集与回显**：表单维护

**列表与导出**：`计划交付日期` 列受 `sales_orders.default.expected_ship_date` 控制，导出跟随可见列

**缺值与残值**：字段被策略隐藏时列表和导出同时隐藏

### 生命周期状态

**真源**：`sales_orders.lifecycle_status`

**采集与回显**：生命周期按钮调用后端 usecase / ProcessRuntime，前端不本地伪造事实状态

**列表与导出**：`状态` 列和导出使用同一状态文案

**缺值与残值**：submit 进入销售订单受理流程，不等于库存、出货、质检或财务事实过账

### 明细行

**真源**：`sales_order_items` 及其产品 / 数量 / 金额快照

**采集与回显**：表单明细区采集和回显

**列表与导出**：当前列表主表不导出明细；`sales_order_items.default` 尚未发布为 active field policy

**缺值与残值**：明细字段未完成页面 / 字段策略 / 打印全链路前，不发布客户配置字段策略

后续若要新增销售订单确认单、出货前确认单或其他销售类打印模板，必须先定义领域模型到打印草稿的 mapper / view model，并补齐表单采集、保存、列表 / 详情 / 导出 / 打印、`fieldRequirements`、`moduleKeys`、服务端 PDF 模块门禁和历史缺值回补测试；不能直接在模板里写死永绅字段、客户抬头、签章或旧资料截图。

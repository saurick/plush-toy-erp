## 维护规则

- `决策类型` 按当前剩余未决部分填写，只使用：产品决定 / 甲方决定 / 混合。已确定的产品基线写在推荐方案中，不把该行自动标成混合；产品正确性和低风险可逆默认不得转嫁为“等甲方确认”，混合项必须拆清各自决定的部分。
- `状态` 只使用：待产品决策 / 待甲方确认 / 讨论中 / 已决策 / 本期不讨论 / 取消。
- 新增问题必须同时填写推荐方案、未确认时安全行为、精确阻塞范围、跟进角色和下一触发点；已有正式会议日期时再写真实截止日期，不猜造日程。
- 甲方决定在确认前只阻塞对应客户切片；其他可独立验证的 Product Core、页面、测试或文档闭环继续推进。
- 不把“已开发”当作问题结论；问题关闭必须回链决策 ID 或明确的“不采用 / 本期不讨论”结论。
- 真实负责人姓名、联系方式和会议原件留在 Private 仓库；本文只写岗位角色。

## 转化规则

```text
需求线索 → 假设 → 推荐方案 → 产品决定或甲方确认 → 实现 → 发布 → 客户验收
```

- 产品默认必须记录适用范围、可逆方式和重新评审触发条件；它是项目 / 产品决定，不是“甲方已确认”。
- 甲方决定必须有受控来源；确认前只让对应高风险分支失败关闭，不阻塞其他可独立闭环项。
- 假设被否定、替代或转成正式决定时，更新状态并回链[决策日志](决策日志.md)，不保留平行运行规则。

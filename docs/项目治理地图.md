## 个人 ToB 交付循环 / Personal ToB Delivery Loop

1. 甲方说明业务目标、关键选择和使用反馈。
2. 项目负责人带回来源与范围，确定可验证的业务切片。
3. Codex 补齐必要实现、异常恢复、验证和文档。
4. 获得发布授权后，按固定版本、目标与恢复点交付。
5. 甲方按实际使用结果反馈，继续处理缺陷、细化或新需求。

甲方不需要逐级签认代码层级或测试内部键。完整责任和授权边界见 [个人开发方式与工作区](../AGENTS.md#个人开发方式与工作区)及[当前开发模式](product/模块实施治理.md#1-当前开发模式)。

## 维护规则 / Maintenance Rules

新增任务或术语时，先检查已有专题；本页只补导航和必要区别，不复制完整规则。文档登记只能证明可找到，不能证明内容正确或能力完成。

目录、职责或路径改变时同步[文档入口](README.md)、[文档清单](文档清单.md)、最近 README 与真实消费者。过程记录、Git 和发布授权继续遵守 AGENTS，不由文档修改或测试通过产生。

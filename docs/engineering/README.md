| 维护权限、业务及流程状态、任务目录、RPC、数值、密码和打印限制 | [跨层公共契约与生成规范](跨层公共契约与生成规范.md) |
| 理解 CI / 发布架构和完成标准 | [持续交付设计](持续交付设计.md)、[验收证据](持续交付设计.md#验收证据-acceptance-evidence) |

`.gitlab-ci.yml` 是 canonical CI/CD 编排，GitHub 只接收供代码审查使用的单向镜像。DEV 工作台投影正式脚本与 GitLab 证据，不进入生产构建。当前 SHA、pipeline、Runner、备份和目标状态使用实时读回，不再维护独立的实施勾选表。

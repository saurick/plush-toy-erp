# 当前真源与交接顺序 / Current Source of Truth

本页帮助确认“查哪份依据”。按任务找文档先看[文档入口](README.md)；本页不重复专题细则、测试结果或目标环境状态。

## 阅读顺序

1. [仓库 README](../README.md)：确认项目入口和本地启动方式。
2. [产品能力进度台账](product/产品能力进度台账.md)：确认当前可用范围与边界；台账不构成待办优先级或实施授权。
3. 对应专题：查业务合同、字段来源和岗位责任。
4. 当前代码、Ent schema、Atlas migration 与测试：核实实现行为。
5. 对应客户的固定版本、目标环境和实际反馈：判断是否已发布、可交付或已验收。

聊天、截图、外部建议、`progress.md` 和归档只作输入或历史线索，不能覆盖当前真源。Product Core 源码包不依赖客户私有资料。

## 当前产品结构

同一套 Product Core 按客户独立私有化部署；当前稳定客户 key 为 `yoyoosun`，`reference-customer` 仅作工程参考。客户 key 不承担 SaaS tenant 语义。

客户差异通过配置、角色、菜单、字段、编号和打印表达；配置只能收窄能力，不能提升后端权限、改 schema 或绕过领域状态机。详见[配置与权限策略](product/配置与权限策略.md)。

## Workflow 与 Fact

Workflow 管协同任务，ProcessRuntime 管已登记节点及白名单领域命令，Fact 管真实业务结果。任务完成不代写库存、质检、生产、出货或财务；出货放行也不等于已出货。

状态、事务、幂等、失败恢复和查询边界统一见[状态与事实边界](architecture/状态工作流事实边界.md)及[业务链与轨迹](architecture/业务链与运行轨迹边界.md)。

## 客户资料、公开资源与导入

客户原始 Excel、PDF、图片、员工信息和私密 manifest 留在客户专属受控存储。产品仓仅保存获准配置、公开资源、合成 fixture 与脱敏映射，普通构建和测试不依赖私有仓或凭据。

当前没有通用客户批量导入执行器。已有辅助录入仍须人工复核并通过正式 usecase 保存，模拟数据不代表真实导入。具体范围见[字段来源规则](product/业务主链路数据流向与字段来源规则.md)和[客户实施流程](product/新增甲方客户实施流程.md)。

## 测试与发布

按[测试策略](product/自动化测试策略.md)选择受影响检查，页面与样式修改需真实浏览器验证。日志与审计口径查[可观测性入口](observability/README.md)。

发布使用 `server/deploy/compose/prod/`，绑定 commit / image、migration、配置、健康检查、业务 smoke 和回滚点；低配目标机只加载制品、迁移、启动和检查。自动化、本地绿色和历史发布均不替代当前目标读回、客户使用反馈或 UAT。

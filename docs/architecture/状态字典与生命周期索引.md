## 采购应付从草稿到结清 / Purchase Payable Example

**草稿 → 已过账 → 已结清**

| 状态 | 一句话理解 |
| --- | --- |
| 草稿 | 应付单已开，等待财务核对 |
| 已过账 | 这笔欠款已经正式记账 |
| 已结清 | 这张应付单的待付金额为 0 元 |

应付 1,000 元，付了 600 元并记到这张单上后，**还欠 400 元**，单据仍是「已过账」。若冲回款项后重新有了待付余额，单据会回到「已过账」。

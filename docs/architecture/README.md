## 维护原则

记录稳定的领域归属与边界；相近对象先核对既有真源，避免别名、双写和重复状态机。Workflow 完成与 Fact 过账始终分开。

边界变化时同步相关实现、消费者和测试；文档同步统一见[索引规则](../README.md#索引同步--index-sync)。阶段过程与目标环境状态分别留在过程记录、部署证据中。

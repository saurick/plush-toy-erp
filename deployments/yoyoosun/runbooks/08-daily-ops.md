# yoyoosun 日常运维 / Daily Operations Runbook

## 每日

- [ ] 检查 server `/healthz`、`/readyz`。
- [ ] 检查 web `/healthz` 和 `/readyz`；前者只证明静态进程存活，后者同时证明后端可用。
- [ ] 检查 `docker compose ps` 是否有异常重启。
- [ ] 检查磁盘使用率。
- [ ] 检查最近备份任务状态。
- [ ] 抽查最近错误日志摘要。
- [ ] 检查登录失败异常和未处理异常任务。
- [ ] 附件文件备份与配套 PG dump / manifest 可定位，记录共同恢复点；PG 定时备份通过不能代替完整系统备份。

## 每周

- [ ] 服务健康。
- [ ] 容器重启次数。
- [ ] 磁盘使用率和增长趋势。
- [ ] 数据库连接数。
- [ ] 慢查询摘要，如已启用。
- [ ] 最近备份状态。
- [ ] 最近恢复演练状态。
- [ ] 最近 7 天错误日志摘要。
- [ ] 登录失败次数。
- [ ] 未处理导入 unresolved queue；当前仅限 dry-run / review。
- [ ] 未处理异常任务。
- [ ] 库存负数检查。
- [ ] 预留过期检查，如当前 release 已开放预留。
- [ ] 审计日志抽查。
- [ ] 证书有效期检查。
- [ ] 巡检报告已脱敏归档。

## 每月

- [ ] 完整备份恢复演练。
- [ ] 权限矩阵复核。
- [ ] 管理员和业务账号复核。
- [ ] 离职 / 无效账号已禁用。
- [ ] 磁盘容量趋势复核。
- [ ] 数据库膨胀检查。
- [ ] known limitations 更新。
- [ ] release evidence 归档。
- [ ] 导入报告归档；当前不包含真实 apply。
- [ ] 安全配置复核。
- [ ] 异常库存复核。
- [ ] 业务闭环 smoke 复核。
- [ ] 备份保留策略和加密状态复核。

## 清理边界

清理前先记录磁盘占用、镜像和容器状态，列明当前 release、回滚版本及恢复证据。只删除已经核对归属、未被任何容器引用且超出回滚保留范围的精确镜像或本轮可重建产物；build cache 也按实际占用和活动构建核对。完成后读回磁盘与容器状态。

常规维护不执行全量 image prune、volume prune，不删除数据库、`/data`、Compose env、附件对象、证书或唯一证据。回滚镜像即使没有运行容器引用，也在保留范围内。附件、数据库、配置和发布证据按各自保留与恢复合同处理，备份要求见[备份恢复](04-backup-restore.md)。
